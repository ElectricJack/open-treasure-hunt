How It Works

  1. Create: Use the web-based builder to design your treasure hunt
  2. Encrypt: Set passwords that unlock sections (from puzzle answers)
  3. Export: Download a single HTML file
  4. Share: Distribute the file to your hunters
  5. Play: Hunters solve puzzles and unlock sections!

Key Features

🔐 Security Model

  • No password data stored anywhere
  • AES-256-GCM encryption
  • PBKDF2 key derivation (100k iterations)
  • Verification only through decryption

🧩 Puzzle Types

  • Text password & riddles
  • Math & logic puzzles
  • Caesar cipher decoder
  • GPS geohash locations
  • QR code scanning
  • Image-based clues

🔑 Key Composition

  • Concatenate multiple answers
  • Reverse order combinations
  • Sorted alphabetically
  • Joined with separators
  • Direct key entry
